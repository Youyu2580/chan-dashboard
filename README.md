# 指数缠论看板（上证 / 创业板 / 科创50）

每天收盘后自动生成一页手机可看的「缠论位置图」：三个指数各一张，给出日线在哪个中枢的上下方、
三买三卖有没有出现（只认第一次回试）、同向笔力度是衰减还是加剧、以及"出现什么才动手"。

- 线上地址：`https://<你的用户名>.github.io/chan-dashboard/`
- 刷新：每交易日北京时间 15:35 / 16:35（GitHub Actions，UTC 07:35 / 08:35）
- 标的：上证指数 `sh000001`、创业板指 `sz399006`、科创50 `sh000688`
- 数据：日线 / 30 分钟取自新浪财经（备用腾讯），月线由日线合成；MACD(12,26,9)

## 页面怎么读

| 位置 | 含义 |
|---|---|
| 顶部三个按钮 | 三个指数的当前信号灯与收盘价，点一下切换 |
| 今日信号 | 红=空仓等；黄=观察、等确认；绿=中枢上方持有 |
| 日线位置 | 收盘价在最近一个日线中枢的上方 / 下方 / 内部 |
| 三买 / 三卖 | 离开中枢后**第一次**回试不回中枢；第二次起只提示、不再算买卖点 |
| 同向笔力度 | 本轮段 vs 前一段：价是否新低 / 新高、DIF 是否抬高、绿柱面积是否缩小 |
| 风控提示 | 把第16课、第20课的退出规则拆成可触发条件 |
| 关键位 | 压力：MA20 / 三卖点 / 中枢下沿；支撑：0.618 / 月线中枢上沿 / 0.786 |
| 信号灯走查回测 | 状态样本 + 切换日样本的未来 5/10/20 日中位数收益与胜率 |
| 口径 vs 原文 | 折叠块，逐条标出本站与原著的差异 |

## 判定口径（可复现，且有明确简化）

1. **包含处理**：有包含关系的两根 K 线合并，向上取"高高"、向下取"低低"。
2. **分型**：处理后的三根 K 线，中间同时高/低者为顶/底分型。
3. **笔**：相邻顶底分型之间至少隔一根独立 K 线（合并后索引差 ≥4）。
4. **中枢**：连续三笔的价格重叠区 `[max(low), min(high)]`；后续笔端点回到区间内算延伸，离开后
   下一笔又回来算震荡回归；延伸超过 9 笔断开（按中枢扩展升级处理）。
5. **三买/三卖**：离开中枢那一笔走完后的**第一次**回试不回到中枢；后续回试只提示不计入。
6. **力度对比（背驰近似）**：同向两段——价格创新低/新高，且（DIF 抬高 或 绿柱面积缩小）。

### 与原著的差距（页面里也标了）

| 本站口径 | 原文 |
|---|---|
| 用**笔**做中枢的最小零件 | 第18/20课：中枢由"三个连续**次级别走势类型**"重叠确定，区间 `[max(a2,b2,c2), min(a1,b1,c1)]` |
| 延伸=笔端点回区间；9 笔截断 | 第20课中心定理一：延伸 ⟺ 任意 `[dn,gn]` 与 `[ZD,ZG]` 有重叠；"9 笔截断"是流行口径，原文没有 |
| 叫"同向笔力度（背驰近似）" | 第16课："没有趋势，没有背驰；背驰是前后趋势间的比较" |
| 三买/三卖只认第一次 | 第20课："并不是任何回调回抽都是第三类买卖点，必须是第一次" |

**结论：这一页是"缠论口径的结构描述 + 走查过的统计"，不是对原著的实现。** 线段没有自动识别，
市场级别的划分跟人工画图会有出入；想严格按原著做，必须补线段（特征序列 + 缺口 + 复杂线段）。

## 结构

```
update.py                      抓数据 → 缠论划分 → 判定 → 回测 → 出页面和图
site/index.html                生成的页面（Actions 每次覆盖）
site/chart_<code>.png          三个指数的日线结构图
site/history.json              每天的结论留档（Actions 自动提交回仓库保活）
site/data.json                 当天结论的结构化快照（含回测数字）
.github/workflows/daily.yml    定时构建 + 发布 Pages
push_api.py                    用一次性 token 建仓/推文件/开 Pages/触发构建
```

## 本地重跑

```bash
pip install pillow
python update.py              # 全量（含回测，约 6-10 秒）
CHAN_FAST=1 python update.py  # 跳过回测，快速看版式
```

生成后打开 `site/index.html`。
