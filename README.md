# 指数缠论看板（上证 / 创业板 / 科创50）

每天收盘后自动生成一页手机可看的「缠论位置图」：三个指数各一张，给出日线在哪个中枢的上下方、
三买三卖有没有出现（只认第一次回试）、同向笔力度是衰减还是加剧、以及"出现什么才动手"。

- 线上地址：`https://<你的用户名>.github.io/chan-dashboard/`
- 刷新：每交易日北京时间 15:35 / 16:35（GitHub Actions，UTC 07:35 / 08:35）
- 标的：上证指数 `sh000001`、创业板指 `sz399006`、科创50 `sh000688`
- 数据：日线 / 30 分钟取自新浪财经（备用腾讯），月线由日线合成；MACD(12,26,9)

## 页面怎么读

| 位置 | 含义 |
|---|---|
| 顶部三个按钮 | 三个指数的当前信号灯与收盘价，点一下切换 |
| 今日信号 | 红=空仓等；黄=观察、等确认；绿=中枢上方持有 |
| **动作（2026-11-28 新增）** | 把「灯＋级别升级」翻成一句能执行的话：绿=持有/回踩加；红=空仓等；黄灯再分三档——日线双背驰买点已现→轻仓试探；5min 升级 ≥3 关→轻仓试探（附止损=5min 起点）；其余→等底分型 / 中枢内不动 |
| **页顶横幅（2026-11-28 新增）** | 任一指数 5min 升级 ≥3 关时，页顶黄条列出各指数走到的关数与起点，不再只藏在折叠块里 |
| 日线位置 | 收盘价在最近一个日线中枢的上方 / 下方 / 内部 |
| 三买 / 三卖 | 离开中枢后**第一次**回试不回中枢；第二次起只提示、不再算买卖点 |
| 同向笔力度 | 本轮段 vs 前一段：价是否新低 / 新高、DIF 是否抬高、绿柱面积是否缩小 |
| **最后一笔（日线）** | 当前这笔的起点 → 终点、是否走完、终点后又走了几根 K 线；笔端停在旧日期就说明结构没在更新 |
| **级别梯** | 日线 / 30min / 5min 各自最后一个中枢 + 现价在中枢的哪一侧 + 距最近边界还要涨跌多少 |
| **级别升级状态机** | 5min 起点之后，"向上笔 → 5min 向上段 → 回踩不破 → 做出 30min 中枢"四关走到第几关 |
| **跳空未补（旁证）** | 级别梯下方的一行小字。缺口**不是缠论要素**，不进任何判定，只是"这个价位区间上还有未补的跳空"这一个事实。 |
| **量价配合** | 量比（当日/前 5 日均量）+ 涨跌方向 → 四象限描述，不做单边判定 |
| **中枢稳定性自检** | 用 T-1/T-2/T-3 的数据重算中枢，看边界漂多少；漂 >5 点说明触发价依赖尾部数据 |
| 风控提示 | 把第16课、第20课的退出规则拆成可触发条件 |
| 关键位 | 压力：MA20 / 三卖点 / 中枢下沿；支撑：0.618 / 月线中枢上沿 / 0.786 |
| 信号灯走查回测 | 状态样本 + 切换日样本的未来 5/10/20 日中位数收益与胜率（样本<30 标"样本不足"，黄灯 20 日期望为负会红字标出） |
| 口径 vs 原文 | 折叠块，逐条标出本站与原著的差异 |

## 数据什么时候更新

每个交易日**两次**（GitHub Actions，cron `35 7,8 * * 1-5` = 北京时间 15:35 与 16:35）：

- 15:35 那次常拿到 **T-1** 的日线（数据源还没更新完）。现在这一趟会直接**跳过发布**、保留上一版，
  不再用昨天的数据覆盖今天的页面；日志里会写"数据滞后…本轮不发布"。
- 16:35 那次覆盖后再看才准，一般 16:50 左右生成完毕。
- 确需用 T-1 数据强制发布时，在 workflow 里给 build 步骤加 `CHAN_ALLOW_STALE=1`。

页面顶部"生成 YYYY-MM-DD HH:MM"就是最后一次构建时间。若某天没有更新，先看
`https://github.com/<用户名>/chan-dashboard/actions` 是否有失败记录（GitHub 的定时任务偶发丢跑）。


## 判定口径（可复现，且有明确简化）

1. **包含处理**：有包含关系的两根 K 线合并，向上取"高高"、向下取"低低"。
2. **分型**：处理后的三根 K 线，中间同时高/低者为顶/底分型。
3. **笔**：相邻顶底分型之间至少隔一根独立 K 线（合并后索引差 ≥4）。
4. **中枢**：连续三笔的价格重叠区 `[max(low), min(high)]`；后续笔的**整笔区间**与该区间有交集即延伸
   （2026-11-24 起，旧版是"笔端点回到区间 + 9 笔截断"，已弃用——端点判据会让中枢上沿偏高，
   同一份数据能差 40 点以上，触发价随之漂移）。
5. **三买/三卖**：离开中枢那一笔走完后的**第一次**回试不回到中枢；后续回试只提示不计入。
6. **力度对比（背驰近似）**：同向两段——价格创新低/新高，且 **DIF 抬高**。只有绿柱面积缩小、
   DIF 仍创新低时，只标"减速待确认"，不叫减速（2026-11-27 修订）。
7. **末端笔击穿校验（2026-11-27 新增）**：最后一笔之后若再创新低/新高，笔端延到极值那根并视为"未走完"，
   避免"底分型成立"被写成"笔已走完（≈一买）"后连续挂在创新低的走势上。5min 级别升级状态机复用同一口径。
8. **级别升级（本站新增，原文无此模块）**：5min 起点（最近创新低的向下笔终点）之后，
   依次检查 ① 向上笔 ② 5min 向上段（后一上笔高点超前一个）③ 回踩不破起点
   ④ 30min 中枢（起点之后形成且现价站住其下沿）。四关全过才算 30min 级别启动。
9. **量价配合**：只做描述不做判定。指数是加权合成，低位放量既可能是出清也可能是破位加速，
   所以不设"缩量=好"的门槛。
10. **数据滞后闸门（2026-11-27 新增）**：任一指数最新日线落后于应有交易日，本轮直接跳过、
    不写任何文件（保留上一版），把发布权留给 16:35 那趟；确需强制发布时设 `CHAN_ALLOW_STALE=1`。
11. **动作列（2026-11-28 新增）**：只做"灯 → 动作"的映射，不改任何缠论判定。优先级固定为
    绿→持有、红→空仓、黄灯内「买点已现」→轻仓试探、「5min 升级 ≥3 关」→轻仓试探（止损取 5min 起点）、
    其余→等底分型/中枢内不动。之所以要这一列：11-24/25 页面写着「≈一买」却是黄灯，用户看不出该不该动手。

### 与原著的差距（页面里也标了）

| 本站口径 | 原文 |
|---|---|
| 用**笔**做中枢的最小零件 | 第18/20课：中枢由"三个连续**次级别走势类型**"重叠确定，区间 `[max(a2,b2,c2), min(a1,b1,c1)]` |
| 延伸＝整笔区间与中枢区间有重叠，不截断（2026-11-24 对齐） | 第20课中心定理一：延伸 ⟺ 任意 `[dn,gn]` 与 `[ZD,ZG]` 有重叠 |
| 叫"同向笔力度（背驰近似）" | 第16课："没有趋势，没有背驰；背驰是前后趋势间的比较" |
| 三买/三卖只认第一次 | 第20课："并不是任何回调回抽都是第三类买卖点，必须是第一次" |
| 月线闸门三态（上/内/下） | 原文无此量化规则，是本站的读法 |
| 缺口 | **不是缠论要素**。原文只在"线段划分的特征序列"里用缺口（有缺口需第三元素确认），是分类判据不是目标位；本站未识别线段，故缺口仅作一行旁证，不进判定 |


**结论：这一页是"缠论口径的结构描述 + 走查过的统计"，不是对原著的实现。** 线段没有自动识别，
市场级别的划分跟人工画图会有出入；想严格按原著做，必须补线段（特征序列 + 缺口 + 复杂线段）。

## 结构

```
update.py                      抓数据 → 缠论划分 → 判定 → 回测 → 出页面和图
site/index.html                生成的页面（Actions 每次覆盖）
site/chart_<code>.png          三个指数的日线结构图
site/history.json              每天的结论留档（Actions 自动提交回仓库保活）
site/data.json                 当天结论的结构化快照（含回测数字）
.github/workflows/daily.yml    定时构建 + 发布 Pages
push_api.py                    用一次性 token 建仓/推文件/开 Pages/触发构建
```

## 本地重跑

```bash
pip install pillow
python update.py              # 全量（含回测，约 6-10 秒）
CHAN_FAST=1 python update.py  # 跳过回测，快速看版式
```

生成后打开 `site/index.html`。
